Tab5 fork patches (required by main/storage/usb_storage.c):
  1. msc_host_vfs_format_t / msc_host_vfs_format_ex(): format with an explicit
     filesystem type (FAT or exFAT) instead of FM_ANY auto-detection.
  2. msc_host_vfs_register_allow_unmounted(): register the VFS/diskio even
     when the filesystem cannot be mounted, keeping the handle alive so the
     caller can format the drive and re-register.
The registry releases (including 1.3.0 and esp-usb master) do not carry this
API; the original upstream firmware was built against a locally patched copy.
